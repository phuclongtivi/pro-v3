# Long Pro V3 — R4B4.1 Result-First Hotfix

- Không còn phát `RESULT_READY` từ một lần bấm nút chung.
- Flash Flow dùng media thật do người dùng chọn và tạo URL xem trước cục bộ.
- Chuỗi có bằng chứng: `SOURCE_SELECTED` → `FLASH_PREVIEW_READY` → `OUTPUT_PREVIEW_READY`.
- `Áp dụng Flow` chỉ mở sau khi preview hợp lệ; kết quả vẫn ở màn hình để người dùng kiểm tra.
- `OUTPUT_PREVIEW_READY` là bản xem trước điều phối Pixel Governor, không được mô tả là file video đã render/xuất.
- Nút/tác vụ chưa có artifact hoặc phản hồi backend chỉ trả `COMMAND_ACCEPTED`.

Kiểm tra phát hành: `npm run audit:eventspace-pixel && npm run build`.
