# FIXFLOW3-R3A — Remove Home Background Music

This patch removes the Home background-music feature from Long App for copyright/store-readiness reasons.

Removed from PRO/MOBI:
- Home music bar and playback controls.
- SoundCloud/Zing playlist endpoint and environment variables.
- Local Long Ambient fallback tracks.
- Startup background-music autoplay.
- Theme/background-music selection UI.

Preserved:
- Studio/Live audio workflows and mixer concepts.
- Microphone/speaker/monitoring configuration surfaces.
- Welcome video media flow.
- All FIXFLOW3-R3 navigation, AI Flash, connection, Store, Sticker, Boss and END logic.
